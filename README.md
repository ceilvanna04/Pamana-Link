# Pamana-Link[cite: 3]

[![Live Demo](https://ceilvanna04.github.io/Pamana-Link/)

The Pamana Print Routing Portal is a responsive, Linktree-style landing page[cite: 3]. It acts as a smart directory that instructs clients exactly where to send their files—routing small PDFs to Messenger and large PSDs to email, preserving print quality and preventing attachment failures[cite: 3]. 

This project was built to streamline print requests for Pamana Media Publishing, Inc., reducing manual inquiries and ensuring customers submit their designs without errors.

## 🚀 Live Demo
Access the live portal here: [ceilvanna04.github.io/Pamana-Link/](https://ceilvanna04.github.io/Pamana-Link/)[cite: 3]

## ✨ Features
*   **Smart File Routing:** Automatically instructs clients on the best platform to send their files based on file size and type (e.g., Messenger vs. Email)[cite: 3].
*   **Print Quality Preservation:** Prevents file compression and attachment failures by directing large files (like PSDs) to email[cite: 3].
*   **QR-Accessible:** Designed to be scanned by customers directly in the shop for immediate access.
*   **Streamlined UI:** Features a simple, 3-button interface that eliminates confusion and directs customers to the right contact channels instantly.
*   **Responsive Design:** Fully optimized for mobile users scanning the QR code from their phones[cite: 3].

## 💡 Background
As a Shop Operations Assistant, I noticed customers frequently experienced issues with file compression and failed attachments when sending their print designs. I developed this portal to bridge the gap between our operations and the customer experience, creating a seamless submission process that saves time for both the staff and the clients.
